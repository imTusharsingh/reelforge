`pipeline.v2` defaults off. V8 switches the UI; T2 removes the flag and remaining old flow. Delete each superseded implementation as its replacement passes, in the same PR or the next. `table.*` means every column in the named legacy table, including tenant keys. Endpoints are relative to `/workspaces/:workspaceId`; marked controllers enumerate verbs and parameters. Shared auth, workspace guard, channel identity, immutable M04 assets/characters, reusable prompt/snapshot/render primitives, M08 ledger, M18 caps, M13 publishing receipts, emergency stop and audit remain. T2 must verify actual remaining consumers and retention before dropping any listed persistence.

Follow-up decisions: V4 templates scriptwriter genre/duration from format and Brief; the V1 seed currently uses an Explainer/30-second compatibility example. `cadence.timezone = "CHANNEL"` is a workspace-default sentinel, never a valid ChannelBrief timezone: V7 resolves it to the channel's IANA timezone before CadenceSchema validation. PRESET assets remain tenant-owned; U1 must decide per-workspace copies versus a global catalog in its ADR. Dedicated bootstrap-provider separation is an optional later refactor; current boot seeding is offline and idempotent.
