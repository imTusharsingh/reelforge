# Deprecation inventory — Wave 0

Owner source: LOCKED v2.0 plan (2026-11-16). Cursor canvas was inaccessible behind a browser challenge; the rows explicitly enumerated in the pasted assignment are covered below. V2–V10 allocations describe replacement boundaries and must be checked against the canvas at review. This inventory does not authorize deletion of retained data.

`pipeline.v2` is off by default. V8 switches UI, T2 removes the old flow. Until replacement consumers exist, deprecated code is still required by the old flow. Delete superseded code in the replacement PR (or its immediately following cleanup), with no stranded dual implementation. Any table/column removal needs a dedicated ADR, migration, history/retention decision and expand/migrate/contract evidence. No table or column is removed by Wave 0.
