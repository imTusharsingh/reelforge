# Deprecation inventory — Wave 0

Verified against Page v2.0 in [issue #112](https://github.com/imTusharsingh/reelforge/issues/112), body and all comments, including its exact deprecation list and final fix prompt. This is the V1 owned-path inventory; deleted code is struck through.

VideoRun is the only generation pipeline. T2 removed the server and web rollback switches, the manual planning, production, review and publish composer screens, and the old generation endpoints and workers. The existing tables remain for historical data and active consumers, including V9 publishing's stored manifest and approval validation. A table or column drop still requires its own ADR and a migration reversible by backup.

`table.*` means every column in the named legacy table, including tenant keys. Endpoints are relative to `/workspaces/:workspaceId`; marked controllers enumerate verbs and parameters. Shared auth, workspace guard, channel identity, immutable M04 assets/characters, reusable prompt/snapshot/render primitives, M08 ledger, M18 caps, M13 publishing receipts, emergency stop and audit remain. T2 must verify actual remaining consumers and retention before dropping any listed persistence.

Follow-up decisions: V4 templates scriptwriter genre/duration from format and Brief; the V1 seed currently uses an Explainer/30-second compatibility example. `cadence.timezone = "CHANNEL"` is a workspace-default sentinel, never a valid ChannelBrief timezone: V7 resolves it to the channel's IANA timezone before CadenceSchema validation. PRESET assets remain tenant-owned; U1 must decide per-workspace copies versus a global catalog in its ADR. Dedicated bootstrap-provider separation is an optional later refactor; current boot seeding is offline and idempotent.
